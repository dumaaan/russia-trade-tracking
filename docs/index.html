Sanctions & trade · 2019–2025

Battlefield goods via Central Asia

After February 2022, EU exports of Common High Priority List (CHPL) goods to Kazakhstan and Kyrgyzstan went up sharply. At the same time, both countries exported much more of the same goods to Russia. This page shows both flows and compares the two countries.

Method and limits

  • CHPL list. EU version of February 2024: 50 HS codes in Tiers 1–4 (integrated circuits, communication parts, bearings, optics, CNC machine tools and others).
  • EU exports. Eurostat Comext, dataset DS-045409, reporter EU-27, HS6 level. Values in EUR are converted to USD with the ECB annual average rate.
  • Exports to Russia. UN Comtrade, as reported by Kazakhstan and Kyrgyzstan. Russia does not publish its trade data after 2021.
  • HS versions. Data for 2019–2021 uses HS 2017. Codes 880730, 852589 and 854149 use their HS 2017 codes (880330, 852580, 854140) in those years.
  • Basket of 49 codes. Code 854149 is not in the totals: its HS 2017 code also has solar cells and LEDs, so the 2019–2021 values would be much too high.
  • Limits. Kazakhstan and Kyrgyzstan are in the Eurasian Economic Union with Russia, with no customs checks on that border, so exports to Russia are probably under-reported. An HS6 code is wider than the sanctioned goods. A rise in both flows can show re-export, but the data alone does not prove it.
